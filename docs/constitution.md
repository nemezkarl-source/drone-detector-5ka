# Рабочая конституция проекта

## Общая структура проекта
/project_root/
├── /docs/         — промты, концепции, заметки
├── /src/          — исходный код, скрипты
├── /hardware/     — схемы, пин-ауты, фото
├── /logs/         — выводы команд, результаты тестов
└── /config/       — конфиги и env

## Роли чатов
- CH1 – Концепция (цели, архитектура, промты в другие чаты)
- CH2 – Железо (платы, драйверы, питание, камеры, GPIO)
- CH3 – ПО (окружения, библиотеки, systemd, зависимости)
- CH4 – Скрипты (детектор, панель, Flask/YOLO и т.п.)
- CH5 – Отладка (логи, FPS, ошибки, стабилизация)

## Формат взаимодействия
1) Один шаг = одно действие. Ответы: делай раз, делай два…
2) Никаких догадок/костылей. Только проверенные инструкции и официальные источники.
3) Язык общения — русский.
4) Минимум шума: команды, код, краткие комментарии.
5) В начале каждого чата фиксируются разрешённые официальные ссылки.
6) Ритм: я выполняю шаг → присылаю вывод → получаю следующий шаг.
7) Фиксация состояний: /docs/CHANGELOG.md или git commit с описанием.
8) Полные пути и окружения в инструкциях.
9) Промты в другие чаты помечаем: “PROMT → CHx: …”
10) Для скорости — новые чаты создаются с этой конституцией и кратким статусом.

## Формат отчёта после каждого шага
➡ Команда: <команда/код>
📄 Вывод: <результат/лог>
🧩 Комментарий: <краткий разбор>

## Цель
Надёжная, повторяемая система от железа до детектора и панели без потерь контекста.
